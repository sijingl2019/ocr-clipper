OCR Clipper：把任何网页变成可编辑的文字和电子书。

很多在线阅读器、文档站点用 canvas 或图片显示正文，无法复制文字。OCR Clipper 先对页面截屏，再交给你电脑上已安装的 AI 智能体（Claude Code、Codex CLI、Hermes，或任意自定义命令）识别文字，还能自动翻页、连续采集，最后整理导出为 EPUB / PDF / TXT / Markdown / HTML。

【主要功能】
• 两种采集模式：只识别当前页面；或连续翻页，自动截屏 → 识别 → 翻到下一页，直到最后一页
• 截屏工具可选：系统自带截图（Win+Shift+S / macOS 截屏）、PixPin、Snipaste、自定义截图命令，或浏览器内置静默截取
• 滚动长截图：自动滚动页面并拼接整页长图，在空白行处切片，不会把文字拦腰切断
• 智能翻页：先按规则识别"下一页 / 下一章 / Next"等按钮；找不到时由智能体根据截图和页面元素判断按钮位置，支持 canvas 渲染的阅读器；识别过的按钮会被记住，之后直接复用；绝不会点击"上一页 / 上一章"
• 本机智能体 OCR：按阅读顺序输出 Markdown，保留标题、段落、列表、表格，自动忽略导航栏、按钮、页眉页脚
• 结果可编辑：每一页都能预览截图、修改文字、调整顺序、单独重新识别
• 一键导出：EPUB（自动生成目录）、PDF（带可搜索的文字层）、TXT、Markdown、HTML；可合并被翻页截断的段落，按标题自动分章，可选附带原始截图

【隐私】
所有截图和识别结果只保存在你自己的浏览器里，并交给你本机的智能体程序处理。扩展不会把任何数据上传到开发者或第三方服务器，没有统计和广告代码。

【使用前准备】
OCR Clipper 需要配合一个本机小组件（Native Messaging host）来调用本机智能体和截图工具：
1. 安装 Node.js 18 或以上版本，以及至少一个智能体命令行工具（如 Claude Code 或 Codex CLI）
2. 从项目主页下载本机组件，运行安装脚本：
   Windows：powershell -ExecutionPolicy Bypass -File host\install-windows.ps1
   macOS / Linux：sh host/install.sh
3. 打开侧边栏，右上角显示"host: win32 / darwin / linux"（绿色）即表示连接成功

项目主页与安装说明：https://github.com/sijingl2019/ocr-clipper

【适用场景】
在线电子书、网页小说、技术文档、知识付费课程讲义、图片型 PDF 预览页等需要把页面内容整理成文字或电子书的场景。请仅用于你有权使用的内容，并遵守相关网站的服务条款与版权规定。
