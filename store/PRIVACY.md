# OCR Clipper 隐私权政策

最后更新：2026-11-02

OCR Clipper（以下简称"本扩展"）尊重并保护你的隐私。

## 我们处理哪些数据

只有在你主动点击"开始"或"导出"时，本扩展才会处理以下数据：

- 你所选网页的截图，以及从截图中识别出的文字；
- 当前标签页的网址和标题，用于标记每一页的来源、判断翻页是否成功；
- 你在设置中填写的配置（智能体命令、截图工具、提示词等）。

## 数据存放在哪里

- 截图、识别结果和设置只保存在你本机浏览器的本地存储（IndexedDB / chrome.storage）中，你可以随时在侧边栏中点击"清空"删除。
- 截图会通过 Chrome Native Messaging 交给**你自己安装在本机**的组件，由你配置的本机智能体程序（例如 Claude Code、Codex CLI）进行识别。这些程序是否联网、如何处理数据，由其各自的服务条款决定。

## 我们不会做的事

- 本扩展不会把任何数据发送到开发者的服务器或任何第三方服务器；
- 不使用分析、跟踪或广告 SDK；
- 不出售、不出租、不共享你的数据。
